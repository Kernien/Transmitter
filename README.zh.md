# Transmitter

🌐 [Русский](README.md) · [English](README.en.md) · [Deutsch](README.de.md) · **中文**

**在自己的设备之间传递链接和小文件——无需注册，不经第三方服务器，端到端加密。**

在手机上复制一个链接，几秒钟后它就出现在电脑上。在办公室把文档拖进窗口，它已经在手机上等着你。所有内容都保存在**你自己的云盘**（目前支持 Dropbox）中，并在设备上直接加密：云盘只能看到毫无意义的字节。

| | |
|---|---|
| 📱 **Android** | 应用，支持系统“分享”菜单 |
| 🖥️ **Windows** | 应用，可将文件拖放到窗口中 |
| 🌐 **浏览器** | https://kernien.github.io/transmitter-web/ ——无需安装 |

版本 **0.1.0** ——首个正式版本。

> **界面语言。** 目前应用界面只有俄语。本指南中的按钮名称先给出中文，括号内是应用中实际显示的文字，例如 **新建密钥**（«Новый ключ»）。

## 为什么做这个

作者厌倦了每次都要想办法在 **Android 的个人资料和工作资料**之间传递链接或文件（工作资料由 [Shelter](https://github.com/PeterCxy/Shelter) 创建）。两个资料彼此隔离，常用的办法——在聊天应用里发给自己、用邮件转发、手动通过云盘复制——要么麻烦，要么根本行不通。

于是有了 Transmitter：在两个资料中都安装它，并连接到同一个库。在一个资料中选择 **分享 → Transmitter**，链接或文件就已经在另一个资料里等着了。在手机、电脑和浏览器之间同样方便。

---

## 功能

- **链接。** 自动识别，轻点即可打开。
- **最大 25 MB 的文件** ——照片、文档、压缩包。使用 📎 按钮、拖放到窗口（Windows 和浏览器），或在 Android 上从任意应用“分享”。
- **双向“分享”（Android）。** 从浏览器、相册或任意应用直接发送到 Transmitter，也可以从 Transmitter 分享到任意应用。
- **多个库。** 例如一个用于“个人资料 ↔ 工作资料”，另一个用于与电脑交换：每个库都有自己的密钥，互不干扰。
- **批量处理条目。** 选中多条后，可打包成一个 zip 下载、分享或删除。
- **在所有设备上删除。** 删除的条目会从所有设备上消失，云盘中的文件也一并删除。
- **无需注册。** 没有 Transmitter 账号：设备之间通过密钥连接——二维码或一串文本。

## 隐私

- **AES-256-GCM 端到端加密。** 链接和文件在发送前加密，只在你的设备上解密。
- **没有自己的服务器。** 数据只保存在你的云盘中单独的 `应用/<应用名称>` 文件夹里。Transmitter 看不到云盘中的其他文件。
- **密钥既是地址也是密码。** 任何拥有库密钥的设备都可以读写该库。只把密钥传给你自己的设备。
- **丢失的密钥无法找回。** 只要至少有一台设备上还有密钥，就可以再次显示它。如果在所有设备上都删除了，就无法再访问该库。

## 安装

### Android

1. 从 [**Releases**](https://github.com/Kernien/Transmitter/releases) 下载 APK：
   - `Transmitter-0.1.0-android-arm64.apk` ——适用于近几年的大多数手机；
   - `Transmitter-0.1.0-android-armv7.apk` ——适用于较旧或入门级机型（如果第一个无法安装）。
2. 在手机上打开该文件。Android 会询问是否允许从此来源（浏览器或文件管理器）安装——请允许。

**工作资料（Shelter）。** 先在个人资料中安装 Transmitter，然后在 Shelter 中选中它，点击 **克隆到工作资料**。在工作资料中登录 Dropbox 也需要浏览器——请把浏览器一并克隆过去。

### Windows

1. 从 [**Releases**](https://github.com/Kernien/Transmitter/releases) 下载 `Transmitter-0.1.0-windows-x64.zip`。
2. 解压到方便的文件夹（例如 `C:\Program Files\Transmitter` 或 `文档\Transmitter`），然后运行 `transmitter.exe`。
3. 首次启动时，Windows 可能提示“Windows 已保护你的电脑”——因为应用没有付费的代码签名证书。点击 **更多信息 → 仍要运行**。

### 浏览器

打开 https://kernien.github.io/transmitter-web/ 。密钥和云盘登录状态会保存在该浏览器中。

## 使用方法

### 1. 第一台设备：创建库

1. 点击 **新建密钥**（«Новый ключ»），输入名称（例如“个人 ↔ 工作”），选择云盘 **Dropbox** → **创建**（«Создать»）。
2. 屏幕上会显示密钥的二维码——可以关闭，之后随时可在 ⋮ 菜单中找到。
3. 点击新建的库 → **登录 Dropbox**（«Войти в Dropbox»）。登录并允许访问，条目列表随即打开。

### 2. 其他设备：连接同一个库

1. 在第一台设备上：库旁边的 ⋮ → **显示密钥 / 二维码**（«Показать ключ / QR»）。
2. 在新设备上：点击顶部的二维码图标 → **扫描二维码**（«Сканировать QR-код»）（手机或带摄像头的浏览器），或粘贴用 **复制密钥**（«Скопировать ключ»）复制的密钥字符串 `TRM1.…`。
3. 登录**同一个** Dropbox 账号，条目列表就会出现。

**同一部手机上的另一个资料。** 无法扫描手机自己屏幕上的二维码，因此请以文本形式复制密钥，并粘贴到另一个资料中的 Transmitter。如果两个资料之间禁止共享剪贴板，可以在电脑或浏览器上显示二维码，再用手机扫描。

### 3. 发送

- **链接** ——粘贴到底部的输入框并点击 ➤。或在 Android 浏览器中选择 **分享 → Transmitter**。
- **文件** ——输入框左侧的 📎（输入框中的文字会成为文件说明），或把文件拖进窗口，或在 Android 上任意应用中选择 **分享 → Transmitter**。

只要条目列表处于打开状态，新内容会在几秒钟内出现在其他设备上。

### 4. 管理条目

- **条目旁的 ⋮：** **分享**（«Поделиться»）、**保存文件**（«Сохранить файл»）、**复制文本**（«Копировать текст»——链接或说明）、**在所有设备上删除**（«Удалить для всех устройств»）。
- **轻点** 链接即可打开，轻点文件即可保存。
- **长按**（或在 ⋮ 菜单中选择 **选择** «Выбрать»）进入多选模式。勾选多条后，在顶部选择：**下载**（一个 zip 压缩包；链接和说明保存在 `сообщения.txt` 中）、**分享** 或 **删除**。
- **标题栏的 ⋮ → 清空列表**（«Очистить ленту»）会在所有设备上删除该库中的全部内容。

### 5. 管理

- **多个库：** 再创建一个密钥，它会有自己的条目列表。
- **云盘：** 主界面上的 ☁ 图标——在此设备上登录或退出云盘。
- **从设备移除库：** 库旁边的 ⋮ → **从设备移除**（«Удалить с устройства»）。云盘和其他设备上的数据不受影响。

## 常见问题

| 现象 | 解决办法 |
|---|---|
| 浏览器没有打开 Dropbox 登录窗口 | 允许该网站弹出窗口；在 Brave 中关闭此地址的 Shields |
| 在工作资料中无法打开 Dropbox 登录 | 用 Shelter 把浏览器克隆到工作资料 |
| “文件大于 25 MB” | 这是 0.1.0 版本的限制：请发送更小的文件或分卷压缩包 |
| 条目没有出现在另一台设备上 | 检查网络，并确认打开的是同一个库；列表每 5 秒刷新一次。在 Shelter 中确认工作资料里的 Transmitter 没有被冻结 |
| “需要重新登录云盘” | 主界面上的 ☁ → **退出**（«Выйти»）→ **登录**（«Войти»） |
| 小米手机无法安装 APK | 为用来打开该文件的应用允许“安装未知来源应用” |
