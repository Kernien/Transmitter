# Transmitter

🌐 [Русский](README.md) · [English](README.en.md) · [Deutsch](README.de.md) · **中文**

**在自己的设备之间传递链接和小文件——无需注册，不经第三方服务器，端到端加密。**

在手机上复制一个链接，几秒钟后它就出现在电脑上。在办公室把文档拖进窗口，它已经在手机上等着你。所有内容都保存在**你自己的云盘**（Dropbox、Google Drive 或 MEGA）中，并在设备上直接加密：云盘只能看到毫无意义的字节。

| | |
|---|---|
| 📱 **Android** | 应用，支持系统“分享”菜单 |
| 🖥️ **Windows** | 带安装程序的应用，可将文件拖放到窗口中 |
| 🐧 **Linux** | AppImage——单个文件，无需安装；已在 Steam Deck 上测试 |
| 🌐 **浏览器** | https://kernien.github.io/transmitter-web/ ——无需安装 |

版本 **0.14.0**。

> **界面语言。** 应用界面有英语和俄语；在中文系统上显示为英语（可在 ⚙ 设置“Settings”中切换）。本指南中的按钮名称先给出中文，括号内是应用中实际显示的英文，例如 **新建密钥**（“New key”）。

## 为什么做这个

作者厌倦了每次都要想办法在 **Android 的个人资料和工作资料**之间传递链接或文件（工作资料由 [Shelter](https://github.com/PeterCxy/Shelter) 创建）。两个资料彼此隔离，常用的办法——在聊天应用里发给自己、用邮件转发、手动通过云盘复制——要么麻烦，要么根本行不通。

于是有了 Transmitter：在两个资料中都安装它，并连接到同一个库。在一个资料中选择 **分享 → Transmitter**，链接或文件就已经在另一个资料里等着了。在手机、电脑和浏览器之间同样方便。

## 功能

- **链接。** 自动识别，轻点即可打开。
- **最大 100 MB 的文件** ——照片、文档、压缩包。每个库在创建时选择大小上限（10、25、50 或 100 MB）。使用 📎 按钮、拖放到窗口（Windows 和浏览器），或在 Android 上从任意应用“分享”。
- **双向“分享”（Android）。** 从浏览器、相册或任意应用直接发送到 Transmitter，也可以从 Transmitter 分享到任意应用。
- **多个库。** 例如一个用于“个人资料 ↔ 工作资料”，另一个用于与电脑交换：每个库都有自己的密钥，互不干扰。
- **批量处理条目。** 选中多条后，可打包成一个 zip 下载、分享或删除。
- **条目备注。** 为链接或文件添加说明（是什么、有什么用），可在任意设备上修改或删除。
- **在所有设备上删除。** 删除的条目会从所有设备上消失，云盘中的文件也一并删除。
- **设备名称。** 每个条目都显示来源设备：“Redmi 10”、“Redmi 10 · work”、“笔记本”。
- **英语和俄语界面。** 语言跟随系统，或在应用中选择。
- **自选外观。** 浅色或深色主题、跟随系统，或选择配色预设：海洋（Ocean）、森林（Forest）、日落（Sunset）、夜晚（Night，纯黑背景，在 OLED 屏幕上更省电）。还有流行的深色编辑器主题：Dracula、Nord、One Dark、Solarized Dark、Gruvbox、Catppuccin Mocha。
- **在列表中直接看照片。** 带图片的条目显示预览，可全屏查看并缩放。较大的照片（超过 10 MB）点击按钮后才加载。
- **在应用内直接阅读文档。** 文本文件（`.txt`、`.csv`、`.json`、`.log`、源代码）、带格式的 Markdown 和 Word `.docx` 文档点击即可打开：可选择、复制，可切换等宽字体。
- **在应用内直接播放视频和音乐**（Android、Windows、浏览器）：支持拖动进度和全屏，几乎支持所有格式（`.mp4`、`.mkv`、`.avi`、`.mp3`、`.flac`…）。播放视频时屏幕不会熄灭；关闭屏幕后音乐仍会继续播放。
- **在其他应用中打开**（“Open in another app”）——适用于任何文件：PDF、`.doc`、压缩包、Linux 上的视频，以及 Transmitter 自身不显示的所有内容。
- **快速，离线也能用。** 条目保存在设备上（与云盘中一样是加密的）：列表立即打开，没有网络时也能显示已保存的内容。打开过的文件也保存在设备上（上限在 ⚙ 设置 → “Storage on this device”中设置，默认 1 GB）。
- **公开看板。** 可将任何库以只读方式开放给任何人：凭读者密钥可以查看、复制和下载条目，但不能修改。读者无需云盘账号。
- **无需注册。** 没有 Transmitter 账号：设备之间通过密钥连接——二维码或一串文本。

## 隐私

- **AES-256-GCM 端到端加密。** 链接和文件在发送前加密，只在你的设备上解密。
- **没有自己的服务器。** 数据只保存在你的云盘中单独的文件夹里（Dropbox 中的 `应用/<应用名称>`，或 Google Drive / MEGA 中的 `Transmitter`）。在 Dropbox 和 Google Drive 中 Transmitter 看不到其他文件；MEGA 无法只授权一个文件夹，但应用只使用自己的文件夹。详见[隐私政策](https://kernien.github.io/transmitter-web/privacy.html)。
- **密钥既是地址也是密码。** 任何拥有库密钥的设备都可以读写该库。只把密钥传给你自己的设备。
- **丢失的密钥无法找回。** 只要至少有一台设备上还有密钥，就可以再次显示它。如果在所有设备上都删除了，就无法再访问该库。

## 安装

### Android

1. 从 [**Releases**](https://github.com/Kernien/Transmitter/releases) 下载 APK：
   - `Transmitter-0.14.0-android-arm64.apk` ——适用于近几年的大多数手机；
   - `Transmitter-0.14.0-android-armv7.apk` ——适用于较旧或入门级机型（如果第一个无法安装）。
2. 在手机上打开该文件。Android 会询问是否允许从此来源（浏览器或文件管理器）安装——请允许。

**工作资料（Shelter）。** 先在个人资料中安装 Transmitter，然后在 Shelter 中选中它，点击 **克隆到工作资料**。在工作资料中登录云盘也需要浏览器——请把浏览器一并克隆过去。

### Windows

1. 从 [**Releases**](https://github.com/Kernien/Transmitter/releases) 下载 `Transmitter-0.14.0-windows-setup.exe` 并运行。它只为当前用户安装（无需管理员权限），并在开始菜单中添加 Transmitter。可在 **设置 → 应用** 中卸载；密钥和云盘登录状态会保留。
2. 首次启动时，Windows 可能提示“Windows 已保护你的电脑”——因为应用没有付费的代码签名证书。点击 **更多信息 → 仍要运行**。

不想安装？`Transmitter-0.14.0-windows-x64.zip` 是便携版：解压到任意位置，运行 `transmitter.exe` 即可。

### Linux 和 Steam Deck

1. 从 [**Releases**](https://github.com/Kernien/Transmitter/releases) 下载 `Transmitter-0.14.0-linux-x86_64.AppImage`。
2. 将文件设为可执行：在文件管理器中右键 → **属性 → 权限 → 可执行**（或运行 `chmod +x Transmitter-*.AppImage`），然后启动。

**Steam Deck：** 以上操作在桌面模式下进行（Steam 键 → 电源 → 切换到桌面）。若想在游戏模式中也能启动 Transmitter，右键点击文件 → **添加到 Steam**，它会出现在库中的非 Steam 游戏里。

Linux 版没有二维码扫描器——请以字符串形式粘贴密钥。密钥和云盘登录信息保存在 `~/.local/share/app.transmitter.transmitter`（仅当前用户可访问）。另有 `Transmitter-0.14.0-linux-x64.tar.gz`：解压后运行 `transmitter` 即可。

### 浏览器

打开 https://kernien.github.io/transmitter-web/ 。密钥和云盘登录状态会保存在该浏览器中。

## 使用方法

### 1. 第一台设备：创建库

1. 点击 **新建密钥**（“New key”），输入名称（例如“个人 ↔ 工作”），选择云盘（**Dropbox**、**Google Drive** 或 **MEGA**）和 **最大文件大小**（“Maximum file size”，创建后无法更改）→ **创建**（“Create”）。
2. 屏幕上会显示密钥的二维码——可以关闭，之后随时可在 ⋮ 菜单中找到。
3. 点击新建的库 → **登录 Dropbox**（“Sign in to Dropbox”，或 Google Drive）。登录并允许访问，条目列表随即打开。MEGA 直接在应用中用邮箱和密码登录（如果开启了两步验证，还需输入验证码）；密码不会被保存。

### 2. 其他设备：连接同一个库

1. 在第一台设备上：库旁边的 ⋮ → **显示密钥 / 二维码**（“Show key / QR”）。
2. 在新设备上：点击顶部的二维码图标 → **扫描二维码**（“Scan QR code”）（手机或带摄像头的浏览器），或粘贴用 **复制密钥**（“Copy key”）复制的密钥字符串 `TRM1.…`。
3. 登录**同一个**云盘账号，条目列表就会出现。

**Google Drive 说明。** 登录时 Google 会提示应用未经验证——请选择 **高级 → 转至 Transmitter**。在手机上登录后点击 **返回 Transmitter**（“Return to Transmitter”）。在浏览器中 Google 只授予约一小时的访问权限，之后需要重新登录。

**同一部手机上的另一个资料。** 无法扫描手机自己屏幕上的二维码，因此请以文本形式复制密钥，并粘贴到另一个资料中的 Transmitter。如果两个资料之间禁止共享剪贴板，可以在电脑或浏览器上显示二维码，再用手机扫描。

### 3. 发送

- **链接** ——粘贴到底部的输入框并点击 ➤。或在 Android 浏览器中选择 **分享 → Transmitter**。
- **文件** ——输入框左侧的 📎（输入框中的文字会成为文件说明），或把文件拖进窗口，或在 Android 上任意应用中选择 **分享 → Transmitter**。
- **照片或视频**（Android）——📎 左侧的 🖼 会打开图库应用，比在文件中查找更方便。

只要条目列表处于打开状态，新内容会在几秒钟内出现在其他设备上。

### 4. 管理条目

- **条目旁的 ⋮：** **添加备注**（“Add comment”，之后为“Edit comment”）、**选择文本**（“Select text”，用于复制其中一部分）、**分享**（“Share”）、**保存文件**（“Save file”）、**复制文本**（“Copy text”——链接或说明）、**在所有设备上删除**（“Delete on all devices”）。
- **轻点** 链接即可打开，轻点文件即可保存。
- **长按**（或在 ⋮ 菜单中选择 **选择**“Select”）进入多选模式。勾选多条后，在顶部选择：**下载**（一个 zip 压缩包；链接和说明保存在 `items.txt` 中）、**分享** 或 **删除**。
- **标题栏的 ⋮ → 清空列表**（“Clear feed”）会在所有设备上删除该库中的全部内容。

### 5. 管理

- **多个库：** 再创建一个密钥，它会有自己的条目列表。
- **设置：** 主界面上的 ⚙ 图标（“Settings”）——外观（“Appearance”）、语言（“Language”：跟随系统、Русский 或 English）以及设备存储（“Storage on this device”，浏览器版没有）。每台设备分别设置。
- **设备名称：** 主界面上的 🪪 图标。首次启动时 Transmitter 会自动建议一个名称。
- **云盘：** 主界面上的 ☁ 图标——在此设备上登录或退出云盘。
- **从设备移除库：** 库旁边的 ⋮ → **从设备移除**（“Remove from device”）。云盘和其他设备上的数据不受影响。

### 6. 公开看板：与他人分享

任何库（Dropbox、Google Drive 或 MEGA 中的）都可以**以只读方式**开放——例如，与朋友或同事分享一组链接或照片。

**所有者：**

1. 库旁边的 ⋮ → **只读访问…**（“Read-only access…”）→ **开放访问**（“Open access”）。使用 Dropbox 时，应用会请你重新登录一次（此窗口中就有“Sign in to Dropbox again”按钮）——这样它才能创建公开链接。
2. 屏幕上会显示**读者密钥**——二维码和 `TRM1R.…` 字符串。把它发给你想分享的人。之后可在同一处再次查看。
3. 然后照常使用这个库：新条目、备注和删除操作会自动同步给读者，大约一分钟内生效。
4. **关闭访问**（“Close access”）——已发出的所有读者密钥都会失效。如果再次开放访问，会生成新的密钥。

**读者：** 顶部的二维码图标 → 粘贴或扫描读者密钥。看板会出现在列表中，并标有“Read-only”。无需云盘账号或登录，浏览器也可以使用。条目可以查看、复制、下载和转发，但不能修改。

读者能看到**库中的全部内容**（包括备注），因此与他人分享时请单独创建一个库。云盘链接中只有加密数据，读者密钥中也不包含库的秘密——无法用它修改库。读者密钥需要 Transmitter 0.7.0 或更高版本才能打开。

## 常见问题

| 现象 | 解决办法 |
|---|---|
| 浏览器没有打开云盘登录窗口 | 允许该网站弹出窗口；在 Brave 中关闭此地址的 Shields |
| 浏览器中的 Google Drive 要求重新登录 | Google 对没有服务器的网页应用只授予约一小时的访问权限。☁ → Google Drive → **登录**（“Sign in”） |
| 在工作资料中无法打开云盘登录 | 用 Shelter 把浏览器克隆到工作资料 |
| “File is larger than N MB” | 这是创建库时选择的上限。如需发送更大的文件，请创建上限更高（最多 100 MB）的库，或发送分卷压缩包 |
| 条目没有出现在另一台设备上 | 检查网络，并确认打开的是同一个库；列表每 5 秒刷新一次。在 Shelter 中确认工作资料里的 Transmitter 没有被冻结 |
| “Sign in to the cloud again” | 主界面上的 ☁ → **退出**（“Sign out”）→ **登录**（“Sign in”） |
| 小米手机无法安装 APK | 为用来打开该文件的应用允许“安装未知来源应用” |
| 输入 `TRM1R.…` 密钥时提示“This isn't a Transmitter key” | 这是公开看板的读者密钥：请将 Transmitter 更新到 0.7.0 或更高版本 |
| 开放只读访问时提示重新登录 Dropbox | 在同一窗口中点击“Sign in to Dropbox again”并允许访问——只需一次 |
| “The owner has closed access to this board” | 此读者密钥已失效——请向所有者索取新的密钥 |
| Linux 上 AppImage 无法启动 | 将文件设为可执行（见“安装 → Linux”）。部分发行版需要安装 `libfuse2` 软件包；Steam Deck 已自带 |
