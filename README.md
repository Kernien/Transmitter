# Transmitter

**Сообщения, ссылки и файлы между своими устройствами — без регистрации, без
чужих серверов, со сквозным шифрованием.**

Отправили ссылку с телефона — через пару секунд она уже на компьютере.
Перетащили документ в окно на работе — он ждёт вас на телефоне. Всё хранится
в **вашем собственном облаке** (сейчас — Dropbox) и шифруется прямо на
устройстве: облако видит только бессмысленный набор байтов.

| | |
|---|---|
| 📱 **Android** | приложение, в том числе меню «Поделиться» |
| 🖥️ **Windows** | приложение, перетаскивание файлов в окно |
| 🌐 **Браузер** | https://kernien.github.io/transmitter-web/ — ничего устанавливать не нужно |

Версия **0.1.0** — первый релиз.

---

## Возможности

- **Текст и ссылки.** Ссылки распознаются автоматически и открываются одним
  нажатием.
- **Файлы до 25 МБ** — фото, документы, архивы. Кнопка 📎, перетаскивание в
  окно (Windows и браузер) или «Поделиться» из любого приложения на Android.
- **«Поделиться» в обе стороны (Android).** Из браузера, галереи, мессенджера —
  прямо в Transmitter; и из Transmitter — в любое приложение.
- **Несколько баз.** Отдельная лента для работы, отдельная для дома: у каждой
  своя «связка ключей», и они никак не пересекаются.
- **Работа с несколькими сообщениями сразу.** Выделите — и скачайте одним
  zip-архивом, поделитесь или удалите.
- **Удаление для всех устройств.** Удалённое сообщение исчезает отовсюду,
  вместе с файлом в облаке.
- **Без регистрации.** Никаких аккаунтов Transmitter: устройства связываются
  QR-кодом.

## Конфиденциальность

- **Сквозное шифрование AES-256-GCM.** Сообщения и файлы шифруются до отправки
  и расшифровываются только на ваших устройствах.
- **Нет своего сервера.** Данные лежат только в вашем облаке, в отдельной папке
  `Приложения/<имя приложения>`. Остальные файлы в облаке Transmitter не видит.
- **Ключ — это и адрес, и пароль.** Любое устройство с ключом базы может читать
  и писать в неё. Передавайте ключ только на свои устройства.
- **Потерянный ключ не восстановить.** Пока ключ есть хотя бы на одном
  устройстве, его можно показать снова. Если удалить его отовсюду — доступ к
  базе пропадёт.

## Установка

### Android

1. Скачайте APK из раздела [**Releases**](https://github.com/Kernien/Transmitter/releases):
   - `Transmitter-0.1.0-android-arm64.apk` — для большинства телефонов
     последних лет;
   - `Transmitter-0.1.0-android-armv7.apk` — для старых или недорогих моделей,
     если первый не устанавливается.
2. Откройте файл на телефоне. Android попросит разрешить установку из этого
   источника (браузера или файлового менеджера) — разрешите.

### Windows

1. Скачайте `Transmitter-0.1.0-windows-x64.zip` из раздела [**Releases**](https://github.com/Kernien/Transmitter/releases).
2. Распакуйте в удобную папку (например, `C:\Program Files\Transmitter` или
   `Документы\Transmitter`) и запустите `transmitter.exe`.
3. При первом запуске Windows может показать «Система Windows защитила ваш
   компьютер» — у приложения нет платной цифровой подписи. Нажмите
   **Подробнее → Выполнить в любом случае**.

### Браузер

Откройте https://kernien.github.io/transmitter-web/. Ключи и вход в облако
запоминаются в этом браузере.

## Как пользоваться

### 1. Первое устройство: создайте базу

1. Нажмите **«Новый ключ»**, придумайте название (например, «Личное») и
   выберите облако **Dropbox** → **«Создать»**.
2. Появится QR-код ключа — его можно закрыть, он всегда доступен в меню ⋮.
3. Нажмите на созданную базу → **«Войти в Dropbox»**. Войдите и разрешите
   доступ — откроется лента.

### 2. Остальные устройства: подключите ту же базу

1. На первом устройстве: ⋮ у базы → **«Показать ключ / QR»**.
2. На новом устройстве: значок QR вверху → **«Сканировать QR-код»** (телефон,
   браузер с камерой) или вставьте строку ключа `TRM1.…` (её можно
   скопировать кнопкой «Скопировать ключ»).
3. Войдите в **тот же** аккаунт Dropbox — и лента появится.

### 3. Отправляйте

- **Текст или ссылка** — поле внизу ленты и кнопка ➤.
- **Файл** — 📎 слева от поля (текст из поля станет подписью к файлу), или
  перетащите файлы в окно, или на Android: **Поделиться → Transmitter** в любом
  приложении.

Новые сообщения появляются на других устройствах в течение нескольких секунд,
пока лента открыта.

### 4. Работайте с сообщениями

- **⋮ у сообщения:** поделиться, сохранить файл, копировать текст, удалить.
- **Нажатие** на ссылку открывает её, на файл — сохраняет.
- **Долгое нажатие** (или «Выбрать» в меню ⋮) включает выделение. Отметьте
  несколько сообщений и вверху выберите: **скачать** (одним zip-архивом с
  файлами и `сообщения.txt`), **поделиться** или **удалить**.
- **⋮ в заголовке ленты → «Очистить ленту»** удаляет всё в этой базе на всех
  устройствах.

### 5. Управление

- **Несколько баз:** создайте ещё один ключ — у него будет своя лента.
- **Облака:** значок ☁ на главном экране — войти в облако или выйти из него на
  этом устройстве.
- **Убрать базу с устройства:** ⋮ у базы → «Удалить с устройства». Данные в
  облаке и на других устройствах останутся.

## Если что-то не работает

| Что происходит | Что делать |
|---|---|
| Браузер не открывает окно входа в Dropbox | Разрешите всплывающие окна для сайта; в Brave — отключите щиты для этого адреса |
| «Файл больше 25 МБ» | Ограничение версии 0.1.0: передавайте файлы поменьше или архивом по частям |
| Сообщение не появилось на другом устройстве | Проверьте интернет и что открыта та же база; лента обновляется раз в 5 секунд |
| «Нужно заново войти в облако» | ☁ на главном экране → «Выйти» → снова «Войти» |
| Xiaomi не даёт установить APK | Разрешите установку из неизвестных источников для приложения, которым открываете файл |
