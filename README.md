# Transmitter

🌐 **Русский** · [English](README.en.md) · [Deutsch](README.de.md) · [中文](README.zh.md)

**Ссылки и небольшие файлы между своими устройствами — без регистрации, без
чужих серверов, со сквозным шифрованием.**

Скопировали ссылку на телефоне — через пару секунд она уже на компьютере.
Перетащили документ в окно на работе — он ждёт вас на телефоне. Всё хранится
в **вашем собственном облаке** (Dropbox или Google Drive) и шифруется прямо на
устройстве: облако видит только бессмысленный набор байтов.

| | |
|---|---|
| 📱 **Android** | приложение, в том числе меню «Поделиться» |
| 🖥️ **Windows** | приложение с установщиком, перетаскивание файлов в окно |
| 🐧 **Linux** | AppImage — один файл без установки; проверено на Steam Deck |
| 🌐 **Браузер** | https://kernien.github.io/transmitter-web/ — ничего устанавливать не нужно |

Версия **0.7.1**. Интерфейс — на **русском и английском**: по языку системы
или на выбор кнопкой 🌐.

## Зачем это

Transmitter появился, потому что автору надоело каждый раз придумывать, как
перекинуть ссылку или файл между **личным и рабочим профилем Android**
(рабочий профиль создан в [Shelter](https://github.com/PeterCxy/Shelter)).
Профили изолированы друг от друга, и привычные способы — отправить себе в
мессенджер, переслать почтой, скопировать через облако вручную — неудобны или
просто не работают.

Теперь Transmitter установлен в обоих профилях и подключён к одной базе:
**«Поделиться» → Transmitter** в одном профиле — и ссылка или файл уже ждут в
другом. Так же удобно и между телефоном, компьютером и браузером.

## Возможности

- **Ссылки.** Распознаются автоматически и открываются одним нажатием.
- **Файлы до 100 МБ** — фото, документы, архивы. Лимит (10, 25, 50 или 100 МБ) выбирается для каждой базы при её создании. Кнопка 📎, перетаскивание в
  окно (Windows и браузер) или «Поделиться» из любого приложения на Android.
- **«Поделиться» в обе стороны (Android).** Из браузера, галереи, любого
  приложения — прямо в Transmitter; и из Transmitter — в любое приложение.
- **Несколько баз.** Например, одна для пары «личный ↔ рабочий профиль»,
  другая для обмена с компьютером: у каждой свой ключ, и они не пересекаются.
- **Работа с несколькими записями сразу.** Выделите — и скачайте одним
  zip-архивом, поделитесь или удалите.
- **Комментарии к записям.** Пояснение к ссылке или файлу — что это и
  зачем; его можно изменить или удалить с любого устройства.
- **Удаление для всех устройств.** Удалённая запись исчезает отовсюду, вместе
  с файлом в облаке.
- **Имена устройств.** У каждой записи видно, откуда она пришла: «Redmi 10», «Redmi 10 · рабочий», «Ноутбук».
- **Русский и английский.** Язык — как в системе или на выбор в приложении:
  удобно, если вы учите язык.
- **Быстро и без интернета.** Записи хранятся на устройстве (зашифрованными,
  как в облаке): лента открывается сразу, а без сети показывает сохранённое.
- **Публичные доски.** Откройте любую базу только для чтения и поделитесь
  ею с кем угодно: по ключу читателя записи можно смотреть, копировать и
  скачивать, но не менять. Аккаунт облака читателю не нужен.
- **Без регистрации.** Никаких аккаунтов Transmitter: устройства связываются
  ключом — QR-кодом или строкой.

## Конфиденциальность

- **Сквозное шифрование AES-256-GCM.** Ссылки и файлы шифруются до отправки
  и расшифровываются только на ваших устройствах.
- **Нет своего сервера.** Данные лежат только в вашем облаке, в отдельной папке
  `Приложения/<имя приложения>` в Dropbox или `Transmitter` в Google Drive.
  Остальные файлы в облаке Transmitter не видит. Подробнее — в
  [политике конфиденциальности](https://kernien.github.io/transmitter-web/privacy.html).
- **Ключ — это и адрес, и пароль.** Любое устройство с ключом базы может читать
  и писать в неё. Передавайте ключ только на свои устройства.
- **Потерянный ключ не восстановить.** Пока ключ есть хотя бы на одном
  устройстве, его можно показать снова. Если удалить его отовсюду — доступ к
  базе пропадёт.

## Установка

### Android

1. Скачайте APK из раздела [**Releases**](https://github.com/Kernien/Transmitter/releases):
   - `Transmitter-0.7.1-android-arm64.apk` — для большинства телефонов
     последних лет;
   - `Transmitter-0.7.1-android-armv7.apk` — для старых или недорогих моделей,
     если первый не устанавливается.
2. Откройте файл на телефоне. Android попросит разрешить установку из этого
   источника (браузера или файлового менеджера) — разрешите.

**Рабочий профиль (Shelter).** Установите Transmitter в личный профиль, затем
в Shelter выберите его и нажмите **«Клонировать в рабочий профиль»**. Для
входа в облако в рабочем профиле тоже нужен браузер — клонируйте туда и его.

### Windows

1. Скачайте `Transmitter-0.7.1-windows-setup.exe` из раздела [**Releases**](https://github.com/Kernien/Transmitter/releases)
   и запустите. Установка — только для вашего пользователя, без прав
   администратора; Transmitter появится в меню «Пуск». Удалить можно в
   **Параметры → Приложения**; ключи и вход в облака при этом сохраняются.
2. При первом запуске Windows может показать «Система Windows защитила ваш
   компьютер» — у приложения нет платной цифровой подписи. Нажмите
   **Подробнее → Выполнить в любом случае**.

Не хотите устанавливать? `Transmitter-0.7.1-windows-x64.zip` — портативная
версия: распакуйте в любую папку и запустите `transmitter.exe`.

### Linux и Steam Deck

1. Скачайте `Transmitter-0.7.1-linux-x86_64.AppImage` из раздела [**Releases**](https://github.com/Kernien/Transmitter/releases).
2. Сделайте файл исполняемым: в файловом менеджере — правой кнопкой →
   **Свойства → Права → «Является исполняемым»** (или
   `chmod +x Transmitter-*.AppImage`), — и запустите.

**Steam Deck:** всё это — в режиме рабочего стола (кнопка Steam → «Питание»
→ «Переключиться на рабочий стол»). Чтобы запускать Transmitter и из
игрового режима, нажмите на файл правой кнопкой → **«Добавить в Steam»** —
он появится в библиотеке среди игр не из Steam.

Сканера QR на Linux нет — ключ вставляется строкой. Ключи и вход в облака
хранятся в `~/.local/share/app.transmitter.transmitter` (доступ только у
вашего пользователя). Есть и архив `Transmitter-0.7.1-linux-x64.tar.gz`:
распакуйте и запустите `transmitter`.

### Браузер

Откройте https://kernien.github.io/transmitter-web/. Ключи и вход в облако
запоминаются в этом браузере.

## Как пользоваться

### 1. Первое устройство: создайте базу

1. Нажмите **«Новый ключ»**, придумайте название (например, «Личное ↔
   рабочее») и выберите облако (**Dropbox** или **Google Drive**) и **максимальный размер файла** (его потом не изменить) → **«Создать»**.
2. Появится QR-код ключа — его можно закрыть, он всегда доступен в меню ⋮.
3. Нажмите на созданную базу → **«Войти в Dropbox»** (или Google Drive). Войдите и разрешите
   доступ — откроется лента.

### 2. Остальные устройства: подключите ту же базу

1. На первом устройстве: ⋮ у базы → **«Показать ключ / QR»**.
2. На новом устройстве: значок QR вверху → **«Сканировать QR-код»** (телефон,
   браузер с камерой) или вставьте строку ключа `TRM1.…`, скопированную кнопкой
   **«Скопировать ключ»**.
3. Войдите в **тот же** аккаунт облака — и лента появится.

**Особенности Google Drive.** При входе Google предупредит, что приложение не
проверено, — нажмите **«Дополнительно» → «Перейти на страницу Transmitter»**.
На телефоне после входа нажмите **«Вернуться в Transmitter»**. В браузере Google
даёт доступ примерно на час, потом нужно войти снова.

**Второй профиль на том же телефоне.** Отсканировать QR с собственного экрана
не получится, поэтому скопируйте ключ строкой и вставьте в Transmitter другого
профиля. Если буфер обмена между профилями запрещён, покажите QR на компьютере
или в браузере и отсканируйте его оттуда.

### 3. Отправляйте

- **Ссылка** — вставьте в поле внизу ленты и нажмите ➤. Или в браузере на
  Android: **Поделиться → Transmitter**.
- **Файл** — 📎 слева от поля (текст из поля станет подписью к файлу), или
  перетащите файлы в окно, или на Android: **Поделиться → Transmitter** в любом
  приложении.
- **Фото или видео** (Android) — 🖼 слева от 📎 открывает Галерею: так снимок
  найти проще, чем в файлах.

Новое появляется на других устройствах в течение нескольких секунд, пока
лента открыта.

### 4. Работайте с записями

- **⋮ у записи:** «Добавить комментарий» (потом — «Изменить комментарий»), «Выделить текст»
  (чтобы скопировать часть), «Поделиться», «Сохранить файл», «Копировать текст»
  (ссылку или подпись), «Удалить для всех устройств».
- **Нажатие** на ссылку открывает её, на файл — сохраняет.
- **Долгое нажатие** (или «Выбрать» в меню ⋮) включает выделение. Отметьте
  несколько записей и вверху выберите: **скачать** (одним zip-архивом;
  ссылки и подписи окажутся в файле `записи.txt`), **поделиться** или
  **удалить**.
- **⋮ в заголовке ленты → «Очистить ленту»** удаляет всё в этой базе на всех
  устройствах.

### 5. Управление

- **Несколько баз:** создайте ещё один ключ — у него будет своя лента.
- **Язык:** значок 🌐 на главном экране — «Как в системе», Русский или
  English. Выбор хранится на каждом устройстве отдельно.
- **Имя устройства:** значок 🪪 на главном экране. При первом запуске Transmitter сам предложит имя.
- **Облака:** значок ☁ на главном экране — войти в облако или выйти из него на
  этом устройстве.
- **Убрать базу с устройства:** ⋮ у базы → «Удалить с устройства». Данные в
  облаке и на других устройствах останутся.

### 6. Публичные доски: поделитесь с другими

Любую базу можно открыть **только для чтения** — например, чтобы делиться
подборкой ссылок или фото с друзьями или коллегами.

**Владелец:**

1. ⋮ у базы → **«Доступ на чтение…»** → **«Открыть доступ»**. Для Dropbox
   приложение один раз попросит войти заново (кнопка «Войти в Dropbox
   заново» прямо в этом окне) — так оно получит право делать публичные ссылки.
2. Появится **ключ читателя** — QR-код и строка `TRM1R.…`. Отправьте его тем,
   с кем хотите поделиться. Показать его снова можно там же.
3. Дальше пользуйтесь базой как обычно: новые записи, комментарии и удаления
   появятся у читателей сами, примерно в течение минуты.
4. **«Закрыть доступ»** — все выданные ключи читателя перестанут работать.
   Если открыть доступ снова, ключ будет новым.

**Читатель:** значок QR вверху → вставьте или отсканируйте ключ читателя.
Доска появится в списке с пометкой «Только чтение». Аккаунт облака и вход не
нужны, подойдёт и браузер. Записи можно смотреть, копировать, скачивать и
пересылать, но не менять.

Читатель видит **всё содержимое базы** вместе с комментариями, поэтому для
обмена с другими заведите отдельную базу. По ссылкам в облаке лежат только
зашифрованные данные, а в ключе читателя нет секрета базы — изменить базу с
ним нельзя. Ключи читателя открываются в Transmitter 0.7.0 и новее.

## Если что-то не работает

| Что происходит | Что делать |
|---|---|
| Браузер не открывает окно входа в облако | Разрешите всплывающие окна для сайта; в Brave — отключите щиты для этого адреса |
| В браузере Google Drive просит войти снова | Так Google ограничивает веб-приложения без сервера: доступ действует около часа. ☁ → Google Drive → «Войти» |
| В рабочем профиле не открывается вход в облако | Клонируйте браузер в рабочий профиль через Shelter |
| «Файл больше N МБ» | Это лимит базы, выбранный при её создании. Для больших файлов создайте базу с лимитом побольше (до 100 МБ) или передайте архив по частям |
| Запись не появилась на другом устройстве | Проверьте интернет и что открыта та же база; лента обновляется раз в 5 секунд. В Shelter проверьте, что Transmitter в рабочем профиле не «заморожен» |
| «Нужно заново войти в облако» | ☁ на главном экране → «Выйти» → снова «Войти» |
| Xiaomi не даёт установить APK | Разрешите установку из неизвестных источников для приложения, которым открываете файл |
| На ключ `TRM1R.…` приложение пишет «Это не ключ Transmitter» | Это ключ читателя публичной доски: обновите Transmitter до 0.7.0 или новее |
| При открытии доступа на чтение — «войдите в Dropbox заново» | Нажмите в том же окне «Войти в Dropbox заново» и разрешите доступ — это нужно один раз |
| «Владелец закрыл доступ к этой доске» | Этот ключ читателя больше не работает — попросите у владельца новый |
| AppImage на Linux не запускается | Сделайте файл исполняемым (см. «Установка → Linux»). На некоторых дистрибутивах нужен пакет `libfuse2`; на Steam Deck он уже есть |
